<details>
<summary>⚙️ Cơ chế hoạt động</summary>

1. Actions checkout → setup Node 22
2. `node scripts/render-metrics.js` fetch `api.github.com/users/toan-05`, tính stars/forks/top-langs → vẽ `assets/metrics.svg` + `assets/metrics.json`
3. `node scripts/render-space.js` vẽ `assets/space-banner.svg` + `assets/space-divider.svg` (thuần SMIL, GitHub render được)
4. Auto-commit nếu file đổi. Snake chạy job riêng [`snake.yml`](./.github/workflows/snake.yml).
